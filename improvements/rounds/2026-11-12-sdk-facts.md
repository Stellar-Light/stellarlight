# 2026-11-12 SDK facts lane

## Scope

An external SDK drift checker reads `/api/analyze?dimension=toolchain` and
infers "deprecated versions" from the 50-row deprecatedRepos sample. Serve
the facts themselves instead: security advisories by version, moved,
renamed and deprecated packages, officially deprecated code patterns, and an
adoption baseline per SDK major. Every fact sourced and dated, and a weekly
check that goes red when a source moves past the table.

Owns: `src/data/sdk-facts.ts`, `src/lib/sdk-facts.ts`,
`scripts/check-sdk-facts.ts`, `.github/workflows/sdk-facts.yml`, the
`sdk-facts` ledger feed. Does not touch `src/lib/soroban-versions.ts` or the
toolchain section of the analyze route and spec (lane/toolchain-truth, spec
1.9.137); the wiring into `toolchain` waits for that lane to merge.
